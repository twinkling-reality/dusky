# Code of Conduct

Dusky welcomes technical disagreement, careful criticism, and evidence that a
current design is wrong. Participants must still treat one another with
respect.

Expected behavior includes:

- discuss code, evidence, and impact rather than attacking a person;
- make room for questions and different levels of experience;
- respect privacy, credentials, and unpublished security reports;
- accept a maintainer's request to stop disruptive or harassing behavior.

Harassment, threats, discriminatory abuse, sexualized attention, publishing
private information, and sustained personal attacks are not acceptable in
project spaces.

Report conduct concerns through the private route described under
[Security reporting](./SECURITY.md#reporting), and identify the report as a
conduct concern. If no private channel is available, do not include sensitive
personal details in a public issue. Maintainers may remove content, close
participation, or block an account when needed to protect the project
community.
